# 요구사항

## 목표
Android 느낌의 미래지향적인 Windows 마우스 커서 팩을 만들고, 우클릭 한 번으로 설치할 수 있게 해서 공개 배포한다.

## 정한 것
- 팩 두 개를 만든다.
  - B 머티리얼 유 파스텔: 연보라 톤 몸체 + 짙은 남보라 테두리.
  - D 캡슐 테일: 흰 화살촉 + 떨어져 따라오는 라임 캡슐.
  - 디자인 결정은 `docs/design.md`에 있다.
- 팩마다 Windows 커서 17종을 모두 만든다.
- 움직이는 커서: 사용 중·백그라운드 작업은 계속 도는 표시, 기본 화살표·링크는 은은하게 숨 쉬듯 변하는 효과. 나머지는 정지.
- 크기 32·48·64·96·128px를 한 파일에 담는다. 화면 배율이 달라도 선명하게 보이게 하기 위해서다.
- 그리는 도구는 Photocraft다. 원본은 `design/*.pcraft` 벡터 도형이다.
  - 커서마다 그룹 `cur/<레지스트리 이름>`, 움직임 프레임은 `anim/<레지스트리 이름>/<번호>`로 둔다.
  - 클릭 지점·프레임 정보는 `design/*-spec.json`에 둔다.
  - 이유: 크게 그린 원본을 실제 크기와 함께 보며 다듬을 수 있고, 내보내기를 스크립트로 되풀이할 수 있다.
- 내보내기는 Python 스크립트로 한다.
  - Photocraft CLI(창 없는 모드)로 원본을 그린 뒤 .cur/.ani로 만든다.
  - 라이브러리는 프로젝트 안 `.venv`에만 설치한다.
- 설치는 팩 폴더의 `install.inf`를 우클릭 → 설치하는 방식이다. 마우스 설정에 구성표로 등록된다.
- 공개 배포: 팩별 zip, 미리보기 이미지가 들어간 README, MIT 라이선스.
- 이름에 "Android"와 그 로고는 쓰지 않는다(상표).

## 하지 않을 것
- macOS·Linux용 커서
- 설정 앱(GUI)
- 왼손잡이용 좌우 반전 세트

## 끝났다고 볼 기준
- 각 팩을 `install.inf`로 설치하면 마우스 설정에 구성표가 뜨고, 17종이 모두 바뀐다.
- 화면 배율 100%·150%·200%에서 흐려지지 않는다.
- 움직이는 커서가 끊기지 않는다.
- 스크립트 한 번이면 원본에서 커서 파일과 zip까지 다시 만들어진다.
- 팩별 zip과 README가 준비되어 있다.
