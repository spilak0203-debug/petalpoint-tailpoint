This cursor pack

INSTALL
1. Extract the zip first. Installing from inside the zip fails.
2. Right-click install.inf and choose Install. Click Yes for admin rights.
3. Settings > Bluetooth & devices > Mouse > Additional mouse settings > Pointers.
   Pick the scheme and press Apply. The settings window does not open by itself.

UNINSTALL (keep this folder - you need uninstall.inf)
1. Right-click uninstall.inf and choose Install. It deletes the cursor
   files and the scheme, and switches cursors back to Windows Default,
   even if you use another scheme now. Re-pick that one in Pointers.
2. Sign out and in, or press Apply in Pointers, to see the change.
3. Windows may ask to restart if a file is in use. An empty folder
   C:\Windows\Cursors\<Name> stays. Delete it if you like.

CAVEATS
- Install overwrites your current cursor settings with no backup.
  Note your current scheme first.
- The scheme goes to the admin account that approves the prompt. If you
  are a standard user and type another admin's password, install from
  the account you will actually use.

이 커서 팩

설치
1. 먼저 zip을 푼다. zip 안에서 설치하면 실패한다.
2. install.inf 우클릭 > 설치. 관리자 권한을 물으면 예.
3. 설정 > Bluetooth 및 장치 > 마우스 > 추가 마우스 설정 > 포인터에서
   구성표를 고르고 적용. 설치 후 설정 창은 자동으로 열리지 않는다.

제거 (이 폴더는 지우지 말 것. uninstall.inf가 필요하다)
1. uninstall.inf 우클릭 > 설치. 커서 파일과 구성표를 지우고 커서를
   Windows 기본값으로 되돌린다. 다른 구성표를 쓰는 중이어도 바뀌니,
   쓰던 구성표는 포인터 탭에서 다시 고른다.
2. 로그아웃 후 다시 로그인하거나 포인터 탭에서 적용을 누르면 보인다.
3. 파일을 쓰는 중이면 다시 시작하라고 할 수 있다.
   빈 폴더 C:\Windows\Cursors\<이름>은 남는다. 필요하면 직접 지운다.

주의
- 설치하면 지금 커서 설정이 백업 없이 바뀐다. 먼저 쓰던 구성표를 적어 둔다.
- 구성표는 관리자 승인 창에 입력한 관리자 계정에 등록된다. 실제로 쓸
  계정에서 설치한다.
